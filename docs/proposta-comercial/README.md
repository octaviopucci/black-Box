# Proposta Comercial — Modelo de Site

Modelos para vender websites a qualquer nicho ou negócio local.

## Arquivos

| Arquivo | Uso |
|---------|-----|
| `Proposta-Comercial-Site-Modelo.pdf` | Proposta completa (6 páginas) para enviar ao cliente |
| `proposta-comercial-site.html` | Fonte editável — abra no navegador, edite e imprima em PDF |
| `proposta-rapida.md` | Versão curta para copiar no WhatsApp |

## Como usar o PDF

1. Baixe `Proposta-Comercial-Site-Modelo.pdf`
2. Substitua os campos `[ASSIM]` (Canva, Word, Pages ou editor de PDF)
3. **Apague a 1ª página** (guia interno) antes de enviar
4. Exporte e envie ao cliente

## Como editar o HTML

1. Abra `proposta-comercial-site.html` no Chrome
2. Edite os textos em amarelo
3. Arquivo → Imprimir → Salvar como PDF

## Proposta rápida (WhatsApp)

Abra `proposta-rapida.md`, copie o bloco, preencha os campos e envie.
