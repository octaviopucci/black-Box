# Script de Abordagem — Advogados (Sorocaba)

> Tom: natural, direto, sem vendedor. Toque na dor e no desejo. Curto.

---

## ESTRUTURA (sempre nesta ordem)

1. **Observação** — algo real que você viu (Google, avaliação, área)
2. **Gap** — o que isso custa pra eles (cliente, credibilidade, caso perdido)
3. **Pergunta** — abre conversa, não empurra venda

---

## 1ª MENSAGEM — abrir conversa

### Versão A (recomendada)
```
Dr(a). [NOME], boa tarde.

Vi o escritório no Google — [X] estrelas e boa reputação local.

Só que quem pesquisa "advogado [área] Sorocaba" hoje compara antes de ligar. Sem site, muita gente nem chega no WhatsApp — vai direto pro concorrente que parece mais estruturado.

Isso já aconteceu aí ou a maior parte ainda vem por indicação?
```

### Versão B (mais curta)
```
Dr(a). [NOME], tudo bem?

Pesquisei advogados em Sorocaba e vi seu perfil no Google — [X] estrelas, bem avaliado.

Curioso: vocês ainda captam cliente só por indicação, ou o Google já traz consulta também?
```

### Versão C (com Instagram ativo)
```
Dr(a). [NOME], boa tarde.

Vi seu perfil — conteúdo consistente e clientes elogiando.

Só notei que no Google não tem site linkado. Quem busca advogado costuma decidir antes de seguir qualquer rede social.

Vocês já pensaram em ter uma página simples só pra passar confiança e filtrar quem liga?
```

---

## FOLLOW-UP 1 (2–3 dias, sem resposta)

```
Dr(a). [NOME], só retomando — sem pressão.

Se quiser, mando um exemplo de como ficaria uma página institucional pro escritório (só visual, 2 min de leitura).
```

---

## FOLLOW-UP 2 (7 dias — último)

```
Dr(a). [NOME], última mensagem por aqui.

Se no futuro fizer sentido organizar a presença no Google, fico à disposição.

Boa semana.
```

---

## QUANDO RESPONDER — descoberta (3 perguntas)

```
Ótimo. Pra eu não te tomar tempo à toa:

1) Qual área vocês mais querem crescer? (trabalhista, cível, família…)
2) Hoje o cliente chega sabendo o que precisa ou ainda "só quer conversar"?
3) Já perderam algum caso porque o cliente foi pro concorrente que "parecia mais sério" online?
```

---

## APRESENTAÇÃO (só depois que responder)

```
Faz sentido.

O que costuma resolver isso é uma página institucional enxuta: áreas de atuação, quem é o advogado, prova social e WhatsApp direto.

Não é sobre "marketing". É sobre o cliente chegar já confiando — e você não precisar se explicar do zero em cada ligação.

Quer que eu te mostre um modelo com a cara do seu escritório?
```

---

## OFERTA (quando pedir valor)

```
Trabalho com 2 formatos:

• **Institucional** — R$ [1.997]: áreas, sobre, depoimentos, contato, mobile
• **Completo** — R$ [2.997]: + SEO local ("advogado [área] Sorocaba") + Google Meu Negócio

Prazo: [10] dias. 50% pra iniciar, 50% na entrega.

Pra seu perfil, o [Institucional/Completo] costuma ser suficiente.
```

✅ Site institucional [NOME DO ESCRITÓRIO]

---

## OBJEÇÕES — respostas curtas

### "Indicação resolve"
```
Indicação é ouro — e continua.

O site não substitui. Só evita perder quem pesquisa no Google e nunca chega a pedir indicação.
```

### "Cliente de advogado não busca no Google"
```
Parte não busca. Parte busca sim — especialmente trabalhista, família, consumidor.

Quem busca já tem urgência. Esse cliente raramente espera indicação.
```

### "Tá caro"
```
Entendo. Dá pra começar enxuto — uma página só, o essencial — por R$ [997/1.497].

Ou deixo anotado. O que prefere?
```

### "Preciso pensar"
```
Claro. Te mando o exemplo visual e retorno [dia]? Sem compromisso.
```

### "Já tenho Instagram"
```
Instagram ajuda na autoridade. Google ajuda na hora H — quando a pessoa precisa de advogado agora e compara 3 opções em 5 minutos.
```
