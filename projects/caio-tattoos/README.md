# Caio Tattoos

Site premium old school baseado no template `estudio-clow-tattoo`.

- **Estilo:** tradicional americano (old school only)
- **Assets:** Instagram @caiotattoos (`public/instagram/`)
- **Contato:** lista de espera via link na bio do Instagram

## Build

```bash
cd projects/caio-tattoos
npm ci
NEXT_BASE_PATH= npm run build
```

Output em `out/`.
