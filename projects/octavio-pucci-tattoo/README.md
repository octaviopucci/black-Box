# StudioClownTattoo

Landing premium em Next.js, refinamento visual do site base44 com mesma estrutura e copy.

## Dev

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Deploy

Importe esta pasta no Vercel ou rode `vercel` na raiz do projeto.

## Notas

- Imagens servidas via CDN base44 (configurado em `next.config.ts`).
- Orçamento abre WhatsApp com mensagem pré-preenchida.
- Projeto standalone: não entra no build unificado Vite da Black Box.
