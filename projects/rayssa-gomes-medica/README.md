# Dra. Rayssa Alexandre — Landing

Landing premium Next.js para **Dra. Rayssa Alexandre Gomes** (`@rayssagomes.medica`).

Medicina de família · Clínica Harmonie · Itapeva/SP.

## Dev

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Deploy

Projeto **standalone** — importe esta pasta na Vercel ou conecte um repo dedicado do cliente.

## Assets

Fotos extraídas do Instagram público (`public/instagram/`). Atualize com `instagram-extract` se URLs expirarem.

## Env

Nenhuma variável obrigatória. WhatsApp e links estão em `src/data/site.ts`.
