# Esfiha Show — Capão Bonito

Landing premium para a unidade de Capão Bonito. Next.js standalone — criado via Black Box agency-site.

## Dev

```bash
npm install && npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build && npm run start
```

## Deploy

Vercel: importe esta pasta ou `vercel --cwd projects/esfiha-show-cb`.
