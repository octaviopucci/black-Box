# Anti-AI Landing Design

Teach the agent to ship one strong composition per viewport — brand-first,
atmosphere-first, never a generic SaaS dashboard collage.

## When to use

- New landing / demo premium / site institucional
- Redesign of hero or first fold
- User says: "sem cara de IA", "site top", "cinematic", "premium", "Awwwards-like"

Also load sibling skill `scroll-cinematic` when the brief includes scroll-linked
video, pinned corridors, or scrubbed timelines.

## Hard rules (composition)

1. **One composition** in the first viewport — not a dashboard.
2. **Brand first**: product/person name is a hero-level signal, not nav text.
3. **Brand test**: if removing the nav makes the page look interchangeable, branding is too weak.
4. **Hero budget** only: brand, one headline, one short support line, one CTA group, one dominant image/video plane.
5. **Full-bleed hero**: edge-to-edge visual plane. No inset hero cards, side-panel heroes, rounded media tiles, or floating image blocks unless the existing design system forces it.
6. **No hero overlays**: no floating badges, promo stickers, chips, or callout boxes on the media.
7. **Cards are rare**: default = no cards. Cards only when they are the interaction container. If removing border/shadow/radius does not hurt UX, remove them.
8. **One job per section**: one purpose, one headline, usually one short support sentence.
9. **Real visual anchor**: product, place, atmosphere, or craft — not abstract purple blobs.

## Typography

- Expressive, purposeful fonts. Avoid Inter / Roboto / Arial / system UI as the display face.
- Pair a strong display face with a quiet text face.
- Huge brand wordmark + smaller editorial headline beats equal-weight text blocks.
- Prefer `clamp()` for display sizes; tight leading on big type (`~0.88–1.05`).

## Color & atmosphere

Define CSS variables for a clear direction (ink, paper, accent, mute).

**Avoid AI-default clusters:**

- Purple-on-white / purple→indigo gradients
- Warm cream `#F4F1EA` + terracotta + high-contrast serif (overused)
- Broadsheet hairline rules + zero radius + dense newspaper columns
- Default dark mode + purple glow + rounded-full pill clusters + multi-layer shadows + emoji

Build atmosphere with gradients, grain, photographic depth, or subtle patterns — not a flat single fill as the whole idea.

## Motion (presence, not noise)

Ship **2–3 intentional motions**, not dozens of micro-animations:

- Hero entrance (word stagger or soft rise)
- One scroll-linked parallax or scrub
- One section reveal or pinned corridor

Always respect `prefers-reduced-motion: reduce` (static fallback, no scrub/pin).

## Content discipline

- Cut pill clusters, stat strips, icon rows, boxed promos, schedule snippets.
- Do not pack stats, addresses, event lists, or secondary promos into the first viewport.
- Copy should sound like the brand voice of *this* client — short, specific, no generic startup slogans.

## Workflow

1. Ask (or infer) brand name, niche, 1 visual reference, primary CTA, and whether video/photo is available.
2. Lock a visual direction in CSS variables before laying out sections.
3. Build hero as full-bleed media + brand + one line + CTA.
4. Add sections with one job each; use scroll craft from `scroll-cinematic` only where it earns presence.
5. Self-check with [references/anti-slop-checklist.md](references/anti-slop-checklist.md).

## Repo anchors (Black Box)

Study existing premium demos before inventing a new language:

- `apps/dr-marcelo-prado` — brand-scale hero + scroll parallax
- `apps/clinica-dna` — pinned horizontal corridor
- `apps/na-veiculos` — cinematic garage pin-scrub
- `apps/clinica-harmonie` / `apps/octavio-pucci` — editorial motion rails

Preserve the established stack of the target app (Vite/React, Framer Motion, GSAP ScrollTrigger, Tailwind) when editing an existing demo.
