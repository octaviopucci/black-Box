# Fonte da metodologia — aula Story Quiz

A VSL `https://aula-storyquiz.xquiz.click/` (SQ - VSL 1) **ensina o método** —
não é o produto a replicar.

Use esta referência para entender **como construir** Story Quizzes; aplique o
método ao produto que o usuário pedir.

## VSL page vs Story Quiz (distinção)

| Peça | URL tipo | Função |
|------|----------|--------|
| **VSL page** | aula-storyquiz.xquiz.click | Vídeo longo + CTA delayado |
| **Story Quiz** | funil interativo 25 telas | Conversão no tráfego pago |

A skill constrói **Story Quiz**. VSL page é opcional e separada (Passo 0 intake).
