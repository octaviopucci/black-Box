# Landing Premium — agency-site kit

Next.js landing gerada pelo kit Premium da skill `/agency-site`.

## Dev

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```

## Customizar

**Um arquivo:** `src/site.config.ts` — copy, links, planos, FAQ, contatos.

**Visual:** substituir placeholders em `public/`:

- `hero.webp` — visual do hero
- `about.webp` — foto about
- props PNG para seção lifestyle (opcional)

## Stack

Next.js · Tailwind · Framer Motion · GSAP · Lenis
