# Márcio Mariano — site premium

Redesign premium e interativo da Imobiliária Márcio Mariano (Capão Bonito/SP).

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion + GSAP

## Desenvolvimento

```bash
npm install
npm run dev
```

No monorepo Black Box:

```bash
npm run dev:marcio
```

Publicado em `/marcio-mariano/`.
