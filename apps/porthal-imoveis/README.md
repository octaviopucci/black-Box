# Porthal Imóveis — site premium

Redesign premium e interativo da Porthal Imóveis Consultoria Imobiliária (Capão Bonito/SP).

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- Framer Motion

## Desenvolvimento

```bash
npm install
npm run dev
```

No monorepo Black Box:

```bash
npm run dev:porthal
```

Publicado em `/porthal-imoveis/`.
