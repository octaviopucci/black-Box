# Jhonatas Gomes — Advogado Trabalhista

Landing premium para **Jhonatas Gomes | Advogado Trabalhista** (`@jhonatasgomes.adv`).

## Fontes

- Instagram embed — fotos, legendas e nome do perfil
- CNPJ público — endereço e telefone do escritório (Santa Rosa de Viterbo/SP)

## Desenvolvimento

```bash
npm --prefix apps/jhonatas-gomes-adv install
npm --prefix apps/jhonatas-gomes-adv run dev
```

## Build

```bash
npm --prefix apps/jhonatas-gomes-adv run build
```

Assets do Instagram em `public/instagram/` (gerados via `instagram-extract`).
