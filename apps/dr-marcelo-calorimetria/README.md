# Calorimetria Indireta — Dr. Marcelo Prado

Site institucional e conceitual para o exame de Calorimetria Indireta (analisador
metabólico portátil) oferecido pelo Dr. Marcelo Prado — Endocrinologia Aplicada.
Direção editorial-científica (Fraunces · JetBrains Mono · Manrope · teal/ink/ember).

## Desenvolvimento

```bash
npm --prefix apps/dr-marcelo-calorimetria install
npm --prefix apps/dr-marcelo-calorimetria run dev
```

## Build

```bash
npm --prefix apps/dr-marcelo-calorimetria run build
```
