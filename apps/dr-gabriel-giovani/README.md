# Dr. Gabriel Giovani

Site corporativo — reabilitação estética e prótese dentária.

## Stack

Vite + React + TypeScript + Tailwind + Framer Motion + GSAP ScrollTrigger

## Desenvolvimento

```bash
npm install
npm run dev
```

## Assets

Imagens extraídas do Instagram oficial `@dr.gabrielgiovani` via `instagram-extract`.
Casos duplicados (post-5/6, post-11, post-16) foram excluídos da galeria.
