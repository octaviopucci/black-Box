# Clínica Vida · Capão Bonito

Landing premium para a Clínica Vida — clínica multidisciplinar em Capão Bonito/SP. Conceito **Impulso**: verde-vida, movimento e cuidado integral. Assets reais do Instagram `@clinicavida_cb`.

## Dev

```bash
npm run dev:vida
# ou
npm --prefix apps/clinica-vida run dev
```

Base de produção no monorepo: `/clinica-vida/`

## Build

```bash
npm run build:vida
```
