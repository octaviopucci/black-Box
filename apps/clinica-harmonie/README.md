# Clínica Harmonie · Itapeva

Experiência digital premium para a Clínica Harmonie (saúde, beleza e bem-estar) — narrativa **Ressonância**, identidade visual própria (ouro, fern, madeira, ink) e conversão via WhatsApp/Instagram.

## Stack

React · Vite · TypeScript · Tailwind · GSAP · Framer Motion · Lucide

## Desenvolvimento

```bash
npm run dev:harmonie
# ou
npm --prefix apps/clinica-harmonie run dev
```

Base de produção no monorepo: `/clinica-harmonie/`
